# Función Lab

[![Abrir Función Lab](https://img.shields.io/badge/Abrir%20la%20p%C3%A1gina-Funci%C3%B3n%20Lab-0aa8cf?style=for-the-badge)](https://funcionlab-urgbqrhr.manus.space/)

**Función Lab** es una plataforma educativa interactiva para explorar funciones lineales, cuadráticas, de valor absoluto, cúbicas, exponenciales y logarítmicas mediante tres representaciones conectadas: expresión algebraica, tabla de valores y gráfica.

## Portada académica

**Autor:** Joan David Arzuza Borja  
**Formación:** Estudiante de Licenciatura en Matemáticas

El propósito del proyecto es ayudar a estudiantes de grados 10 y 11 a comprender las funciones como reglas que pueden leerse desde diferentes perspectivas. La página permite modificar parámetros, observar transformaciones, comprobar puntos, practicar valores y resolver retos con retroalimentación. La nueva expansión añade una estación 3D para pasar de curvas a superficies y un laboratorio libre para superponer varias funciones sin reemplazarlas.

## Entra a la página

Visita la experiencia publicada: **[funcionlab-urgbqrhr.manus.space](https://funcionlab-urgbqrhr.manus.space/)**

El repositorio conserva el código y el historial de desarrollo. La página publicada es el lugar para interactuar con el laboratorio.

## Qué incluye

- Seis familias de funciones con ejemplos guiados.
- Sincronización entre ecuación, gráfica y tabla.
- Controles de zoom, desplazamiento y comparación de escala.
- Tabla interactiva que destaca el punto seleccionado en la gráfica.
- Práctica rápida y retos variables.
- Tema oscuro de alto contraste.
- Asistente educativo en español.
- Portada académica con fotografía, autoría y explicación del propósito.
- Laboratorio 3D con planos, paraboloides, conos, sillas de montar, cilindros y esferas.
- Laboratorio libre con hasta seis funciones superpuestas y parámetros independientes.

## Tecnologías

La interfaz usa HTML, CSS y JavaScript nativos dentro de `dist/`. El servidor mínimo sirve los archivos estáticos y el endpoint seguro del asistente de IA. No se usa base de datos.
